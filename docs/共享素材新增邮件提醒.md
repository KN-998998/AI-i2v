# 共享素材新增邮件提醒

本工具在能访问公司共享目录的办公室 Windows 电脑上运行，不依赖 ECS。每周任务递归扫描配置的共享目录；发现新文件后，把该次扫描发现的文件路径汇总到一封 QQ 邮箱提醒中，提醒及时上传到 OSS。

## 行为约定

- 首次运行只建立已有文件的基线，不发送历史素材提醒。
- 后续只把此前未见过的文件视为新增；已有文件内容修改不会触发提醒。一个扫描批次至少包含一张 `.jpg`、`.jpeg`、`.png` 或 `.webp` 图片才会发信；空目录和仅有非图片文件的批次不提醒。
- 提醒邮件汇总新增文件数、涉及的子文件夹数、数据总量，并列出新增文件的相对路径。
- 邮件发送成功后才更新扫描记录；共享目录扫描或邮件发送失败时保留旧记录，供下次任务重试。
- 扫描记录默认保存在当前 Windows 用户的 `%LOCALAPPDATA%\AssetUpdateNotifier\state.json`，也可用 `ASSET_UPDATE_STATE_PATH` 指定其他本机路径。
- 扫描范围包括共享目录及其子目录内的所有普通文件，不跟随符号链接。

## 本机配置

在办公室电脑上，为运行计划任务的 Windows 用户设置以下用户环境变量。可通过 Windows“编辑当前用户的环境变量”配置；设置后重新登录或重启计划任务，使新环境变量生效。

| 变量名 | 用途 |
| --- | --- |
| `ASSET_UPDATE_SCAN_ROOT` | 共享目录的 UNC 绝对路径，例如 `\\文件服务器\共享名\素材`；不要使用映射盘符 |
| `ASSET_UPDATE_EMAIL_TO` | 接收提醒的邮箱地址 |
| `QQ_SMTP_USER` | 用于发信的 QQ 邮箱地址 |
| `QQ_SMTP_AUTH_CODE` | QQ 邮箱 SMTP 授权码，不是邮箱登录密码 |
| `ASSET_UPDATE_STATE_PATH` | 可选；扫描记录的本机完整路径 |

授权码只配置在本机用户环境变量中，不要发到聊天、写入源码、提交到 Git 或放进邮件日志。QQ SMTP 使用 `smtp.qq.com:465` SSL。

## 每周运行

先用运行计划任务的同一个 Windows 用户手动运行一次，确认共享目录可访问并建立基线：

```powershell
python -X utf8 .\scripts\asset_update_notifier.py
```

然后在 Windows“任务计划程序”创建基本任务：

1. 触发器选择“每周”，设置为星期日 20:00（使用办公室电脑的本地时区）。
2. 操作选择“启动程序”，程序填写当前 Python 环境中 `python.exe` 的完整路径。
3. 添加参数填写 `-X utf8 ".\scripts\asset_update_notifier.py"`；“起始于”填写项目根目录实际路径。
4. 任务使用能访问共享目录且已配置上述环境变量的 Windows 用户运行。使用 UNC 路径，不依赖交互登录后才映射的网络盘。
5. 可在任务计划程序中手动运行任务；首次运行只建立基线，之后扫描到新增文件才会发邮件。

共享目录若要求单独的网络凭据，应先确认计划任务账户能访问该 UNC 路径。任务运行时电脑需开机并能连接公司网络；电脑关机或断网期间不会扫描。

## 验证

```powershell
python -m pytest tests\backend\test_asset_update_notifier.py -q
python -X utf8 .\scripts\asset_update_notifier.py
```

测试覆盖首次基线、仅通知新增文件、重复扫描不重复通知，以及邮件发送失败后的下次重试。真实邮件发送还需在办公室电脑配置有效的 QQ SMTP 授权码，并确认网络允许连接 QQ SMTP。
