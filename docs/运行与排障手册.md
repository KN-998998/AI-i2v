# 运行与排障手册

本手册面向日常开发、测试和运营验收，提供最短启动路径、页面检查点和非破坏性排障方法。

## 本地启动

### 推荐入口

双击根目录 `start_dev.bat`。该脚本会：

1. 检查并停止占用 `127.0.0.1:8015` 的旧进程。
2. 构建前端静态文件。
3. 启动 FastAPI 后端。
4. 打开流程画布。

常用地址：

| 地址 | 用途 |
| --- | --- |
| `http://127.0.0.1:8015/canvas-mvp` | 流程画布 |
| `http://127.0.0.1:8015/workflow/assets` | 素材与菜品 |
| `http://127.0.0.1:8015/workflow/tasks` | 任务中心 |
| `http://127.0.0.1:8015/workflow/weekly-plan` | 周计划生产 |
| `http://127.0.0.1:8015/docs` | API 文档 |

### 手动启动

仅在需要分开调试时使用：

```powershell
scripts\build_frontend.bat
python -m uvicorn web.app:app --host 127.0.0.1 --port 8015 --reload
```

请使用实际项目 Python 3.11 环境。Windows 上若 `npm` 被 PowerShell 执行策略阻止，使用 `npm.cmd`。

## 验收清单

### 新草稿流程

1. 打开 `/workflow/assets`，确认只有第 1 步可编辑。
2. 未上传素材时，图片处理、提示词装配及后续步骤应保持锁定。
3. 上传素材并生成图片处理结果后，确认第 3 步才会解锁。
4. 未完成前两步时，“实时装配”应为禁用状态。
5. 依次完成每个真实产物后，确认只解锁紧随的下一步。

### 编辑抽屉

1. 从节点或步骤卡片点击“编辑”。
2. 右侧应滑出约半屏宽度的编辑抽屉，底层页面不被挤压。
3. “不保存”、关闭按钮、遮罩点击和 Escape 均应收起抽屉并恢复编辑前状态。
4. “保存并收起”应保留更改并关闭抽屉。

### 辅助工作台

流程画布、任务中心和周计划生产应始终可访问；它们不改变制作步骤的产物解锁规则。

## 验证命令

```bat
scripts\verify.bat
```

或分项执行：

```bat
cd frontend
npm.cmd run typecheck
npm.cmd run test
npm.cmd run build
cd ..
python -m pytest
```

本地测试和构建只能验证代码与模拟/静态逻辑；Kling、GoodsMatting、Qwen 等真实调用还取决于账户、密钥、额度、网络和服务可用性。

## 常见问题

| 问题 | 先做什么 |
| --- | --- |
| 页面仍显示旧样式 | 运行 `scripts\build_frontend.bat`，刷新页面并确认地址为 `127.0.0.1:8015` |
| 直接路由返回错误页 | 检查 FastAPI 静态资源回退路由和前端构建是否完成 |
| 步骤错误解锁或错误锁定 | 检查各步骤的真实产物字段与 `frontend/src/workflowProgress.ts`；不要仅看节点文案状态 |
| 抽屉不显示或页面被挤压 | 检查 `Inspector` 是否作为覆盖层渲染，以及 `.step-page-grid` 是否仍保留旧编辑栏列 |
| 上传失败 | 检查单文件是否超过 50 MB、接口日志、可用磁盘和网络 |
| 外部生成失败 | 记录任务 ID、状态、时间与错误信息；核对 `.env` 配置和服务账户，不要把密钥发到日志或工单 |
| 片段无法合成 | 确认已选中片段存在本地 `sourcePath` 且通过预检 |
| 服务无法启动 | 检查 `8015` 端口、Python 依赖、前端构建结果与后端启动窗口 |

## 证据收集

提交问题前，请提供脱敏后的信息：

- 页面 URL、页面标题和复现步骤
- 任务 ID、当前状态、最近事件和发生时间
- 浏览器控制台错误或后端日志片段（不得包含密钥）
- 相关草稿 ID 和节点类型
- 是否已执行前端构建和页面刷新

不要通过清空浏览器站点数据、删除草稿目录或删除媒体文件作为第一反应；先收集证据并确认影响范围。
