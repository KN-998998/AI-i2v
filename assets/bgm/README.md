# 默认曲库

`default/` 里的音乐是成片的默认 BGM：第 6 步没有上传自己的音乐时，每条成片会从这里按任务号稳定地挑一首，几条成片下来轮着用。第 6 步也可以指定其中一首，指定后批量生产的每条成片都用它。

## 音频文件不进 git

这个仓库是公开的。免费 BGM 站点通常允许把曲子用在视频里，但不允许把音频文件本身再分发；把 mp3 提交到公开仓库就是再分发。所以 `.gitignore` 里的 `*.mp3` 把它们挡在外面，仓库里只有这份说明。

部署到服务器时，把本机的 `assets/bgm/default/` 整个文件夹一起拷过去（或者用环境变量 `DEFAULT_BGM_DIR` 指到服务器上放音乐的目录）。

## 要求

- 格式：mp3 / m4a / wav / aac，44.1 kHz 立体声最好（成片音轨就是 44.1 kHz）。
- 长度不限：短于成片会循环，长于成片会截断，结尾自动淡出。
- 音量不用调：合成时会把整条成片统一到 −14 LUFS。
