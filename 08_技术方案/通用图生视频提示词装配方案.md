# 通用图生视频提示词装配方案（1.5-3s 片段）

> 版本：v1.0 ｜ 日期：2026-08-14
> 用途：**给 AI 编程工具的实现规格**——按此文件修改项目现有提示词生成环节
> 目标模型：可灵 Kling 3.0（API 2.0，模型独立端点 `/image-to-video/kling-3.0`）
> 目标时长：1.5-3s（生成 3s 后 ffmpeg 掐头去尾，或 multi-shot 拆 1-2s 镜）
>
> 历史方案记录：当前实现已迁移为画布工作流，实际模块为
> `pipeline/prompt_assembler.py`、`pipeline/kling.py`、

## 1. 任务概括（给人看，**绝不放进 prompt 字符串**）

本模块的目标是：把「一张菜品静态图 + 用户对画面元素/动态的选择」装配成一条**结构化、无歧义、可被视频扩散模型直接执行**的提示词。

设计意图：
- 图片已定义主体、摆盘、环境 → prompt 不做任务描述（"基于参考图生成…"、"保持与原图一致"），只描述**动态、镜头、光线、锁定**。
- 可灵是扩散模型不是 LLM：任务概括词（参考图/生成/保持一致）在视觉空间无对应物，是纯噪声 + 注意力浪费。
- **任务概括放本文件顶部 + 代码注释**；**组装示例放 §9 验收用例**；**实时预览放 UI（用户选完槽位后展示最终 prompt）**。

## 2. 核心设计原则（违反前必须先问）

| # | 原则 | 原因 |
|---|---|---|
| P1 | **槽位化，不扁平拼接** | 每段只承载一个指令，段间物理隔离，不互相打架；工具可整段替换 |
| P2 | **空槽位整段删除，禁止写"无XX"** | 写"无火焰"= 在正向框里念火焰的名字 |
| P3 | **不写任务概括/示例进 prompt** | 扩散模型会把"例如寿司"真的渲染进画面 |
| P4 | **3s 最多承载 2 个次级动态** | ~90 帧，点 3 项以上每项退化成"轻微抖动"（原 prompt"简单位移"成因） |
| P5 | **锁定层逐个点名**（筷子、酱碟，不写"其他元素"） | 泛指约束力远弱于点名 |
| P6 | **负向 = 基础组 + 模式追加 + L1追加 + L2专属追加** | 通用负向压不住各动态的翻车方式 |
| P7 | **首尾帧模式写路径不写状态** | 端点已由图像给定，复述端点会和图像抢控制权 → 中间闪切 |
| P8 | **无自由文本框** | 条件句（"若图中有紫苏则…"）模型不做判断；通用性靠前端槽位解决 |

## 3. 数据模型（槽位定义）

### 3.1 L0 · 画面元素勾选（前置步骤）

用户勾选这张图里有什么（**多选**）：

```
菜品主体 / 配菜装饰 / 餐具器皿 / 桌面台面 / 手部 / 厨师上半身 / 背景陈设
```

勾选后路由：**选 1 个进 L1，最多选 2 个进 L2，其余全部自动进 L3 并逐个点名**。

### 3.2 L1 · 主运动对象（单选，必填）

| L1 选择 | 动作幅度槽位 | 自动生成的正向描述 |
|---|---|---|
| 菜品本体·冷 | 不激活 | 菜品与摆盘保持原位不动，仅湿润切面高光随镜头角度缓慢滑移 |
| 菜品本体·热 | 不激活 | 菜品保持原位不动，仅表面油光随镜头角度缓慢流动 |
| 餐具器皿 | 不激活 | 餐具保持原位不动，仅釉面/金属反光随镜头角度缓慢滑过 |
| 手部 | ✅ 三档激活 | 见 3.3 |
| 厨师上半身 | ✅ 三档激活 | 见 3.3 |
| 无（纯运镜） | 不激活 | 画面内所有元素保持完全静止，仅视角变化 |

### 3.3 动作幅度三档（仅 L1 = 手部/厨师上半身 时激活）

| 档位 | 正向措辞模板 | 成片率 | 工具行为 |
|---|---|---|---|
| ① 存在感级 | 手保持当前姿势与握持关系不变，仅有极轻微自然稳定微动 | 高 | 默认档 |
| ② 片段级 | 手{动词}的动作片段，动作缓慢连贯，握持关系不变，动作不完成 | 中 | 正常 |
| ③ 完整级 | {主体}在3秒内缓慢完成一次{动词}并自然停住 | 低 | **弹提示，建议改走首尾帧模式** |

**动词库（下拉）**：撒落调味 / 淋下酱汁 / 轻扶盘沿 / 缓慢转动餐盘 / 夹起食材 / 切下一刀 / 端起餐盘 / 摆放装饰

**面部处理（自动）**：
- L1=手部 → 负向追加 `人物面部，全身入镜`
- L1=厨师上半身 → 正向追加 `面部表情平静自然，五官稳定`

### 3.4 L2 · 次级动态（多选，上限 2 项）

| L2 选项 | 正向措辞 | 专属追加负向词 |
|---|---|---|
| 热气/蒸汽 | 极轻缓热气自{部位}持续缓慢上升，不成团、不遮挡主体 | 浓烟，白雾遮挡，云雾成团，烟雾旋转 |
| 液体·倾倒 | 细流从{容器}匀速落下，落点固定，流量恒定 | 飞溅，液体倒流，液面暴涨，外溢，容器变形，液体凭空出现 |
| 液体·晃动 | {汤汁/酒液}表面极轻微晃动，反光随之位移，液面不溢出 | 沸腾，翻涌，液面剧烈起伏，溢出 |
| 火焰/炙烤 | 小簇火焰边缘轻微摇曳，火势范围不变 | 火势蔓延，冒黑烟，食材碳化，焦化加深，爆燃 |
| 冰雾/冷凝 | 极淡冷雾贴表面缓慢流动，冷凝水珠保持附着不滑落 | 水珠滑落，结霜蔓延，融化，白雾弥漫 |
| 高光滑移（兜底） | 湿润表面高光随镜头角度缓慢滑移 | — |
| 织物/植物飘动 | {对象}边缘极轻微自然飘动 | 剧烈飘动，形变 |
| 人物微动（配角） | 人物保持姿态不变，仅极轻微呼吸起伏与自然眨眼 | 五官变形，手指畸形，表情夸张，身体扭曲 |

### 3.5 L3 · 锁定层（自动生成，不给用户改）

把 L0 勾选中**未进 L1/L2** 的元素逐个点名拼接：

```
【锁定】筷子、酱碟、青紫苏叶、黑色桌面保持绝对静止，位置、数量、形状、颜色不变。
```

## 4. 模板 A：单图模式

```
【镜头】{A}，极慢匀速，单镜头一镜到底，画面{B}。
【主运动】{L1}。
【次级动态】{L2}，幅度极小，不影响主体形态。
【锁定】{L3}保持绝对静止，位置、数量、形状、颜色不变。
【光线】光源固定，明暗关系不变，无重新打光。
【节奏】动作与运镜同步开始，全程连续无停顿，末端自然减速停住。
```

- `{A}` = 镜头起点（如 45度侧前方中近景）+ 推进方向；`{B}` = 画面属性锚点（如 真实广告级质感，浅景深）
- 空槽位整段删除。

---

## 5. 模板 B：首尾帧模式

```
【过渡】从首帧画面平滑连续过渡到尾帧画面，单镜头一镜到底，无切换、无叠化。
【主运动】{L1过渡动作}，{F速度曲线}。
【次级动态】{L2}，全程连续不中断。
【锁定】{L3}在整个过渡过程中保持位置与形态不变。
【光线】光源固定，明暗随视角连续渐变，不跳变。
【节奏】过渡末端稳定停在尾帧状态。
```

**L1 过渡措辞**（写路径不写状态）：

| L1 类型 | 首尾帧下的过渡措辞 |
|---|---|
| 手部/厨师 ③完整级 | 手连贯自然地从首帧姿态过渡到尾帧姿态，完成一次{动词}，中途不停顿、不回退 |
| 菜品本体 | 菜品位置与形态不变，仅视角与高光从首帧状态连续过渡到尾帧状态 |
| 纯运镜 | 镜头从首帧机位连续{运动}至尾帧机位 |

**F 速度曲线**：全程匀速（默认推荐）/ 慢起匀速收 / 匀速慢收

## 6. 负向提示词组装

```
negative_prompt = 基础组 + 模式追加 + L1追加 + L2各项专属追加（去重后拼接）
```

**基础组（恒定）**：

```
变形，融化，收缩，蠕动，主体位移，新增元素，元素消失，多余的手，文字，logo，水印，抖动，晃动，快速运镜，镜头切换，分镜，画面跳变，曝光跳变，闪烁，重新打光，色彩漂移，涂抹感，二次构图，画质劣化
```

**首尾帧模式追加**：

```
闪切，跳帧，转场特效，叠化，画面突变，中途重构，动作回退
```

**L1/L2 追加**：见 3.3 面部处理 + 3.4 各选项专属负向词。

## 7. 参数映射（可灵 API 2.0 修正版）

> ⚠️ **修正 CC 讨论稿**：可灵 API 2.0 **没有 cfg_scale 参数**（SD 系参数，可灵不支持）。不需要配置它。以下为可灵真实支持的 settings：

```json
{
  "settings": {
    "audio": "off",
    "resolution": "1080p",
    "duration": 3,
    "multi_shot": false
  },
  "options": {
    "watermark_info": { "enabled": false }
  }
}
```

| 参数 | 值 | 说明 |
|---|---|---|
| duration | **3**（整数） | 可灵 3.0 最短 3s，生成后 ffmpeg 掐头去尾取 1.5-2.5s |
| multi_shot | **false** | **必须显式关闭**，否则 3s 可能被切成多镜，切片素材直接报废 |
| resolution | 1080p | 首尾帧模式强制 1080p |
| audio | off | 无声生成，后期配音 |

## 8. 冲突校验（工具必须内置）

| 规则 | 处理 |
|---|---|
| L1 与 L2 指向同一对象 | 报错阻断 |
| L2 超过 2 项 | 阻断，提示"3秒最多承载2个次级动态" |
| 火焰 + 冰雾 同选 | 互斥，阻断 |
| 液体·倾倒 + 镜头推进 | 高风险，警告（推进会拉长流体路径，极易飞溅） |
| 动作幅度=③ + 单图模式 | 弹窗引导切首尾帧 |
| 无缝循环 + (液体倾倒 / 动作幅度②③) | 互斥，阻断 |
| 用户自由文本框 | 不提供；L2 的 target 文本加 5 条校验（长度/标点/条件词/否定词），UI 用下拉候选兜底 |

## 11. 禁令清单（给 AI 编程工具）

1. **禁止**把任务概括/示例加回 prompt 开头（P3）
2. **禁止**给空槽位补"无次级动态"占位句（P2）
3. **禁止**合并镜头动作（如"先推近再环绕"→ 单镜头只能一个运镜）
4. **禁止**添加 cfg_scale 参数（可灵 API 不支持）
5. **禁止**把 L2 上限从 2 放开（P4）
6. **禁止**提供自由文本框（P8）
7. **禁止**在锁定层用泛指（"其他元素"），必须逐个点名（P5）
8. **禁止**删除冲突校验（§8）
9. **禁止**改 multi_shot 默认值（必须 false）
10. 以上任何一条需要违反时，**先问用户**，不许自行决定
